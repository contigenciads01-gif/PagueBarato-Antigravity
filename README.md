# PagueBarato — Central de Agentes

Dashboard e motor de inteligência de custos, precificação e margens para revenda no Mercado Livre com importações via 1688.

## Como Instalar e Rodar

1. **Instalar dependências**:
   ```bash
   pnpm install
   ```

2. **Aplicar migrações do banco de dados**:
   ```bash
   pnpm db:migrate
   ```

3. **Executar testes**:
   ```bash
   pnpm test
   ```

4. **Executar verificações de código**:
   ```bash
   pnpm lint
   pnpm typecheck
   ```

5. **Iniciar ambiente de desenvolvimento**:
   ```bash
   pnpm dev
   ```
